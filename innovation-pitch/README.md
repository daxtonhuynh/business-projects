# CAFÉ · Agri-Food Startup Case Study

A static English-language portfolio page for Team Care Bears’ CAFÉ project.

## Preview and publish

- Open `index.html` locally, or serve this folder with `python3 -m http.server 8000`.
- For a standalone GitHub Pages repository, copy the contents of this folder into the repository root. In **Settings → Pages**, choose **Deploy from a branch**, then select the branch and **/ (root)**.
- To add the case study to an existing portfolio, copy the entire folder into its published source and link to `cafe-portfolio/`. Keep the stylesheet and assets alongside the HTML.

The site uses relative local asset paths, plain HTML and CSS, and no build step. The project demo is an external link. The award is the competition result. Sales and costs on the page are pitch projections in CAD.
